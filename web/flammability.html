    How to read this

    Conditions are grouped the same way the ranking tool groups them: oxygen in steps of 5 percentage points, pressure in steps of 0.1 atm, up to 2 atm. A test counts as not burning only when its recorded outcome says extinction or disruption. Every other test in the group, including one whose outcome was not written down, counts as kept burning. That is the ranking tool's rule, so the two pages agree; the table shows how many tests had no outcome so you can judge each block yourself.

    This is Phenox's reading of historical test outcomes, not a NASA flammability certification. All of these tests were done in microgravity; the Moon and Mars have partial gravity, which NASA's database does not cover yet. The ranking tool adds two downgrade rules for scenarios outside the tested range, which a single block cannot show.
